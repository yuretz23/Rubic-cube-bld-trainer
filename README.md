# Тренажер сліпої збірки кубика Рубіка

Односторінковий тренажер під власну методику: буфери UR (ребра) та UFR (кутові), картинка на кожній наклейці.

- `index.html` — тренажер: схема, скрамбли, перевірка історії, формули, тренування, Bluetooth-кубик Giiker.
- `bld-data.js` — назви, емодзі та зображення наклейок. Оновлюється кнопкою «Зберегти у файл bld-data.js» у режимі редагування (олівець).

Bluetooth-кубик працює в Chrome та Edge на комп'ютері й Android. На iPhone доступне все, крім Bluetooth.

Розбір Bluetooth-пакетів Giiker (розкладка даних і таблиці наклейок) зроблено за реалізацією в [csTimer](https://github.com/cs0x7f/cstimer), яка поширюється під GPLv3.
